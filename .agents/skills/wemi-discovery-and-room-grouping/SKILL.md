## 1. Core Responsibilities & Domain Ownership

The **Antigravity Device Discovery & Room Grouping Agent** owns the internal logic connecting raw LAN UPnP/SSDP responses to organized, human-meaningful rooms in Room v5 SQLite:

1. **Multi-Stage SSDP & Unicast Discovery Orchestration ([`DiscoveryCoordinator.kt`](../../app/src/main/java/org/suppressingfire/wemi/data/DiscoveryCoordinator.kt), [`HomeProfileSanitizer.kt`](../../app/src/main/java/org/suppressingfire/wemi/data/HomeProfileSanitizer.kt), [`DeviceCrudAndRulesCoordinator.kt`](../../app/src/main/java/org/suppressingfire/wemi/data/DeviceCrudAndRulesCoordinator.kt), [`SsdpDiscoveryEngine.kt`](../../app/src/main/java/org/suppressingfire/wemi/network/SsdpDiscoveryEngine.kt), [`DeviceDescriptorFetcher.kt`](../../app/src/main/java/org/suppressingfire/wemi/network/DeviceDescriptorFetcher.kt))**:
   - Coordinates UDP multicast `M-SEARCH` (`239.255.255.250:1900` with `MulticastLock` + `550ms` retransmit within a `1.25s` window), deterministic loopback UDP test mirroring (`registerLoopbackSsdpPort`), order-preserving `Semaphore(3)` concurrent Stage A/B descriptor probing via `LanRuntimeUtils.expectedHardwareIdentity`, placeholder-serial-safe Stage B known-device 9-port unicast verification across `/setup.xml` and `/Lightsetup.xml` via [`LanHttpClient.kt`](../../app/src/main/java/org/suppressingfire/wemi/network/LanHttpClient.kt) / [`NetworkClient.kt`](../../app/src/main/java/org/suppressingfire/wemi/network/NetworkClient.kt) / [`DeviceDescriptorFetcher.kt`](../../app/src/main/java/org/suppressingfire/wemi/network/DeviceDescriptorFetcher.kt), manual-IP 9-port hardware enrichment + `<serialNumber>`/`<UDN>` deduplication (`saveDevice`, matching canonical UDN whenever either side lacks a real serial and preserving hardware `<friendlyName>` when Name is left blank), trimmed home- & room-scoped `moveDeviceOrder(..., withinRoomOnly)`, and multicast-zero Stage C `/24` subnet unicast sweeps (`shouldRunUnicastSubnetFallback` + `Semaphore(24)` across `49153, 49152, 49154, 49151` via Wi-Fi-bound `wifiSocketFactory`, skipping `localIp`, already-verified `skipIps`, and `10.22.22.x`, with `onlySweepWhenKnownMissing = true` during reconnects).
   - Serializes device adoption via `adoptMutex` (`HomeProfileSanitizer.kt`), isolates per-device `Mutex` locks via `DeviceEntity.concurrencyKey()` (`expectedHardwareIdentity` → `"$ipAddress:$port"`), registers immediate `<100ms` Real-LAN GENA push subscriptions with 3-tier `NOTIFY` routing (`!isPlaceholderSerial(serialNumber)` → `"dev_${id}"` → `sourceIp` in `GenaSubscriptionManager.kt` & `GenaAndHealthPollingCoordinator.kt`), and bounds all SOAP `GetBinaryState` probes with the shared `Semaphore(3)` so 2nd-Gen RTOS switches (`WLS040` / `WLS0403` / `WDS060`) never drop TCP connections.
2. **Deterministic 3-Tier / 4-Pass Hardware Identity Resolution (`DeviceEntity.matchesDiscovered`, `matchesDiscoveredDevice` & `findMatchingExistingDevice`)**:
   - **Tier 1 / Pass 1 (`<serialNumber>` via `!LanRuntimeUtils.isPlaceholderSerial`)**: If both `existing.serialNumber` and `discovered.serialNumber` are real non-placeholder serials (excluding blank, `"UNKNOWN"`, and `221517K01018AB` / `LAN` / `NEW` in [`LanRuntimeUtils.kt`](../../app/src/main/java/org/suppressingfire/wemi/network/LanRuntimeUtils.kt)), they match **if and only if** `existing.serialNumber.equals(discovered.serialNumber, ignoreCase = true)`. Never cross-match two switches with different real serial numbers even if DHCP swapped their IP addresses (including inside `NetworkClient.probeWemoPort` & `executeWithPortHealing`) or if multiple loopback simulators run on `127.0.0.1`.
   - **Tier 2 / Pass 2 (`<UDN>` / `USN` via `LanRuntimeUtils.canonicalHardwareUdn`)**: Strips any `::urn:...` SSDP `USN` service suffix (`substringBefore("::")`) and rejects UDNs synthesized from placeholder serials; when **both** sides carry non-empty canonical UDNs, `matchesDiscovered` returns `cleanUdn.equals(cleanDiscoveredUdn, ignoreCase = true)` directly (never falling through to Tier-3 on UDN mismatch), and `probeWemoPort` / `executeWithPortHealing` enforce Tier-2 UDN verification via `expectedHardwareIdentity`.
   - **Tier 3 / Passes 3a & 3b (Exact Endpoint → `<friendlyName>` Fallback)**: Used **only** when at least one side lacks a real serial and canonical UDN; `findMatchingExistingDevice` matches exact `(ipAddress, port)` (Pass 3a) before falling back to case-insensitive `name` (Pass 3b) so two factory-named switches (`"WeMo Light Switch"`) never cross-match.
3. **Automatic Room Inference & Non-Destructive Legacy Room Migration ([`DeviceEntities.kt`](../../app/src/main/java/org/suppressingfire/wemi/data/DeviceEntities.kt))**:
   - **`normalizeDeviceNameForInference(deviceName)`**: Splits CamelCase boundaries (`"StairwayLight"` → `"stairway light"`, `"MasterBathVanity"` → `"master bath vanity"`) and replaces `_`, `-`, `/`, `.` with spaces before lowercase token matching.
   - **`inferRoomFromName(deviceName)`**: Evaluates room categories in specificity order:
     1. **`"Kitchen"`** (`"kitchen"`, `"pantry"`, `"island"`, `"breakfast"`, `"nook"`, `"undercabinet"`, `"under cabinet"`, `"countertop"`)
     2. **`"Dining Room"`** (`"dining"`, `"buffet"`, `"hutch"`, `"china cabinet"`)
     3. **`"Ensuite"`** (`"ensuite"`, `"en suite"`, `"bath"`, `"powder"`, `"vanity"`, `"restroom"`, `"lavatory"`, `"shower"`, `\bwc\b`) — **must precede `"Bedroom"`** so `"Master Bath"`, `"Guest Bathroom"`, `"Primary Bath"`, and `"Kids Bath"` resolve to **`"Ensuite"`**.
     4. **`"Hallway & Landing"`** (`"hallway"`, `\bhall\b`, `"landing"`, `"stair"`, `"foyer"`, `"entry"`, `"vestibule"`, `"mudroom"`, `"mud room"`, `"corridor"`, `"breezeway"`)
     5. **`"Bedroom"`** (`"bedroom"`, `"bedside"`, `"nightstand"`, `"night stand"`, `"headboard"`, `"dresser"`, `"wardrobe"`, `\bbed\b`, `"crib"`, `"cradle"`, `"loft"`, `"master"`, `"primary"`, `"nursery"`, `"guest"`, `"bunk"`, `"dorm"`, `"girls"`, `\bgirl\b`, `"boys"`, `\bboy\b`, `"kids"`, `\bkid\b`, `"children"`)
     6. **`"Outdoor"`**, **`"Garage"`**, **`"Basement"`**, **`"Office"`**, **`"Living Room"`** (with word-bounded `\bden\b`)
     7. **`"Unassigned"`** fallback (normalized via `roomName.trim().ifBlank { "Unassigned" }` across `MainActivity.kt`, `TvScreen.kt`, `DeviceActionsUiController.kt`, `moveDeviceOrder`, `toggleRoomPower`, and `updateRoomBrightness`, and sorted after all named rooms).
   - **`resolveDeviceRoomAssignment(existingRoomName, deviceName, discoveredRoomName, isDemoMode)`**:
     - Preserves custom user-assigned rooms (e.g., `"Porch & Entryway"`), preserves Demo Showroom rooms when `isDemoMode == true`, and automatically migrates Real LAN switches whose `existingRoomName` is blank, `"Unassigned"`, or stuck in legacy `"Living Room"` (when `inferredRoom != "Living Room"`).
4. **Zero-Permission Subnet Home Sync & Soft-AP SSID Shielding (`sanitizeAndResolveInitialLanHome`, `syncFirstRouterSsid`, `mergeDiscoveredMetadata`, `isWemoDeviceSetupSsid` in [`HomeProfileSanitizer.kt`](../../app/src/main/java/org/suppressingfire/wemi/data/HomeProfileSanitizer.kt) & [`XmlAndSkuParser.kt`](../../app/src/main/java/org/suppressingfire/wemi/network/XmlAndSkuParser.kt))**:
   - Filters out Belkin soft-AP SSIDs (`WeMo.Switch.xxx`, `Wemo.LS3W.xxx`, `WeMo.Light.xxx`, `WeMo.Mini.xxx`) from `GetMetaInfo` field 4, preserves already-known router SSIDs on re-adoption, syncs valid router SSIDs onto generic home labels without stale `HomeNetworkEntity` clobbering, and repairs any previously polluted `HomeNetworkEntity` or `DeviceEntity` rows on startup.

## 2. Six Non-Negotiable Discovery, Room Grouping & Release Invariants

Whenever modifying `DeviceEntities.kt`, `DiscoveryCoordinator.kt`, `HomeProfileSanitizer.kt`, `DeviceCrudAndRulesCoordinator.kt`, `LanRuntimeUtils.kt`, `SsdpDiscoveryEngine.kt`, `NetworkClient.kt`, `DeviceDescriptorFetcher.kt`, `SwitchRepository.kt`, `DeviceActionsUiController.kt`, `MainActivity.kt`, `TvScreen.kt`, or `TvRoomSectionHeader.kt`, verify all six invariants:

1. **Unrecognized or Blank Names/Rooms Must Default to `"Unassigned"`, Never `"Living Room"`**:
   - Keep `else -> "Unassigned"` in `inferRoomFromName`, normalize `roomName.trim().ifBlank { "Unassigned" }` consistently across `MainActivity.kt`, `TvScreen.kt`, `DeviceActionsUiController.kt`, `moveDeviceOrder`, `toggleRoomPower`, and `updateRoomBrightness`, and keep `"Unassigned"` sorted at the bottom of `availableRooms` / `groupedDevicesByRoom` and `groupedByRoom` (`TvFocusTarget.RoomHeader` / `TvRoomSectionHeader`, navigated deterministically via Up/Down from all 3 columns with `Left`/`Right` `-10%`/`+10%` room dimming).
2. **`"Ensuite"` Must Be Evaluated Before `"Bedroom"`**:
   - Compound names like `"Master Bath Vanity"`, `"Guest Bathroom Light"`, and `"Kids Bath Fan"` must resolve to `"Ensuite"`, never `"Bedroom"`.
3. **Short Ambiguous Tokens Must Use Pre-Compiled Word-Boundary Regexes**:
   - Always use `WORD_BED_REGEX` (`\bbed\b`), `WORD_HALL_REGEX` (`\bhall\b`), `WORD_DEN_REGEX` (`\bden\b`), `WORD_GIRL_REGEX` (`\bgirl\b`), `WORD_BOY_REGEX` (`\bboy\b`), `WORD_KID_REGEX` (`\bkid\b`), and `WORD_WC_REGEX` (`\bwc\b`) after `normalizeDeviceNameForInference`.
4. **All Discovery, Manual-IP Save, GENA Push & Reconnect Flows Must Enforce `!LanRuntimeUtils.isPlaceholderSerial`, `LanRuntimeUtils.canonicalHardwareUdn`, `LanRuntimeUtils.expectedHardwareIdentity`, `DeviceEntity.concurrencyKey()`, and `resolveDeviceRoomAssignment`**:
   - Never bypass real-serial or canonical-UDN mismatch protection (including inside `probeWemoPort` and `executeWithPortHealing`), never treat synthetic placeholder serials or placeholder-derived UDNs as real hardware identities in Stage B known-device deduplication, `saveDevice`, GENA `deviceKeyFor`, or per-device `Mutex` keys, never overwrite hardware `<friendlyName>` via `ChangeFriendlyName` when Name is left blank, and never overwrite custom user room assignments.
