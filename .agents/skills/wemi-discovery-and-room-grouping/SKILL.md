## 2. Seven Non-Negotiable Discovery, Room Grouping, On-Device Rules & Release Invariants

1. **Unrecognized or Blank Names/Rooms Must Default to `UNASSIGNED_ROOM` (`"Unassigned"`), Never `"Living Room"`**.
2. **Evaluate Specific Functional Rooms (`"Ensuite"`) Before Broad & Floor Modifiers (`"Bedroom"`, `"upstairs"`/`"downstairs"`)**.
3. **Short Ambiguous Tokens Must Use Pre-Compiled Word-Boundary Regexes (`RoomAndCategoryRules.kt`) after `Locale.US` Normalization**.
4. **Enforce 3-Tier / Symmetric 4-Pass Hardware Identity, RFC 6598 CGNAT Safety & `resolveDeviceRoomAssignment` Across All Discovery, Provisioning, Manual Save, GENA, Rules Write & Widget Flows** (aborting `storeValidatedRulesDb` / `syncDeviceTime` on DHCP mismatch).
5. **Zero-RTT Discovery Overhead & Hardened Anti-Brick Rules Safety**:
   - Never issue `/rulesservice.xml` or `FetchRules` inside bulk SSDP/unicast scans (`SsdpDiscoveryEngine` reads Tier-1 hints from `/setup.xml` and gates Stage C descriptors with `Semaphore(3)`).
   - Never misclassify `PVT-OWRT-*` firmware as unsupported when `<rtos>1</rtos>` is present, never downgrade offline switches or generic HTTP `500` faults to `VERIFIED_UNSUPPORTED`, open rules DBs with `NO_LOCALIZED_COLLATORS`, reject WAL headers (`header[18..19] != 1`), strip `'`, `"`, `;`, `--`, `/*`, `*/`, CR/LF, NUL in editable rules & `LOCATIONINFO`, reject `"Unsuccessful!"`/SOAP faults in `isStoreRulesSuccess`, enforce canonical backup path confinement in `noBackupFilesDir`, isolate unowned/shared `RuleID`s, never fabricate real-LAN UDNs, always use `CAST(RuleID AS INTEGER) = CAST(? AS INTEGER)` on typeless `RULES.RuleID`, and never bypass pre-write backups, `HardwareRulesSafetyValidator`, or post-store `FetchRules` verification.
   - Keep `SwitchDatabase.MIGRATION_5_6` and `MIGRATION_6_7` non-destructive so existing user homes, switches, rooms, and cached capabilities survive upgrades intact.
6. **Unit, Hardware Rules, ChromeOS, Governance, Widget & E2E Tests Must Pass (`100%` `< 500L` `.kt` Files, `0` Lint Errors, `100644` Script Modes)**:
   - Run `sh gradlew testDebugUnitTest --rerun-tasks lintDebug assembleDebug` covering all tests including `HardwareRulesTest`, `HardwareRulesMutationTest`, `HardwareRulesE2ETest`, `LifecycleAndConcurrencyTest`, `DiscoveryAndGroupingIntegrationTest`, `ChromeOsArcVmDiscoveryTest`, `ChromeOsArcVmE2ETest`, and `LicenseAndBrandGovernanceTest`.
