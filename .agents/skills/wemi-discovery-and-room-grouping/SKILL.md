## 1. Core Responsibilities & Domain Ownership

The **Antigravity Device Discovery & Room Grouping Agent** owns the internal logic connecting raw LAN UPnP/SSDP responses to organized, human-meaningful rooms in Room v5 SQLite and Home Screen widgets:

1. **Multi-Stage SSDP & Unicast Discovery Orchestration ([`DiscoveryCoordinator.kt`](../../app/src/main/java/org/suppressingfire/wemi/data/DiscoveryCoordinator.kt), [`HomeProfileSanitizer.kt`](../../app/src/main/java/org/suppressingfire/wemi/data/HomeProfileSanitizer.kt), [`ProvisioningCoordinator.kt`](../../app/src/main/java/org/suppressingfire/wemi/data/ProvisioningCoordinator.kt), [`DeviceCrudAndRulesCoordinator.kt`](../../app/src/main/java/org/suppressingfire/wemi/data/DeviceCrudAndRulesCoordinator.kt), [`SsdpDiscoveryEngine.kt`](../../app/src/main/java/org/suppressingfire/wemi/network/SsdpDiscoveryEngine.kt), [`DeviceDescriptorFetcher.kt`](../../app/src/main/java/org/suppressingfire/wemi/network/DeviceDescriptorFetcher.kt), [`DeviceActionsUiController.kt`](../../app/src/main/java/org/suppressingfire/wemi/ui/DeviceActionsUiController.kt))**:
   - Coordinates UDP multicast `M-SEARCH` (`239.255.255.250:1900` with `MulticastLock`, `ensureActive()` cancellation, `selectSearchTargetAndScan` superseded-job cancellation, and `550ms` retransmit within `1.25s`), deterministic loopback UDP test mirroring (`registerLoopbackSsdpPort`), order-preserving `Semaphore(3)` concurrent Stage A/B descriptor probing via `LanRuntimeUtils.expectedHardwareIdentity`, placeholder-serial-safe Stage B known-device 9-port unicast verification across `/setup.xml` and `/Lightsetup.xml` (unescaping XML entities in `<friendlyName>` & `<MetaInfo>` via `XmlAndSkuParser.unescapeXml`), manual-IP 9-port hardware enrichment + `<serialNumber>`/`<UDN>` deduplication (`saveDevice`), trimmed home- & room-scoped `moveDeviceOrder(..., withinRoomOnly)`, and multicast-zero Stage C `/24` subnet unicast sweeps (`shouldRunUnicastSubnetFallback` + `Semaphore(24)` across `49153, 49152, 49154, 49151` via Wi-Fi-bound `wifiSocketFactory`, skipping `localIp`, already-verified `skipIps`, and `10.22.22.x`, with `onlySweepWhenKnownMissing = true` during reconnects).
   - Serializes device adoption via `adoptMutex` (`HomeProfileSanitizer.kt`, prioritizing exact serial/UDN/endpoint matches before name-only candidates in `adoptDiscoveredDevices`), isolates per-device `Mutex` locks via `DeviceEntity.concurrencyKey()`, registers immediate `<100ms` Real-LAN GENA push subscriptions with 3-tier `NOTIFY` routing, and bounds all SOAP `GetBinaryState` probes with the shared `Semaphore(3)` so 2nd-Gen RTOS switches (`WLS040` / `WLS0403` / `WDS060`) never drop TCP connections.
2. **Deterministic 3-Tier / Symmetric 4-Pass Hardware Identity Resolution (`DeviceEntity.matchesDiscovered`, `SsdpDiscoveredDevice.matchesEndpointOrSerial`, `findMatchingExistingDevice`, `findMatchingDiscoveredDevice` & `WidgetRemoteViewsBuilder.resolveTargetDevice`)**:
   - **Tier 1 / Pass 1 (`<serialNumber>` via `!LanRuntimeUtils.isPlaceholderSerial`)**: If both sides carry real non-placeholder serials (excluding blank, `"UNKNOWN"`, and `221517K01018AB` / `LAN` / `NEW`), they match **if and only if** the serial numbers match (case-insensitive). Never cross-match two switches with different real serial numbers across SSDP scans, `10.22.22.1` provisioning, Home Screen widgets, or `probeWemoPort` / `executeWithPortHealing`.
   - **Tier 2 / Pass 2 (`<UDN>` / `USN` via `LanRuntimeUtils.canonicalHardwareUdn`)**: Strips any `::urn:...` SSDP `USN` service suffix (`substringBefore("::")`) and rejects UDNs synthesized from placeholder serials; when **both** sides carry non-empty canonical UDNs, `matchesDiscovered`, `matchesEndpointOrSerial`, `saveDevice`, `ProvisioningCoordinator`, and `WidgetRemoteViewsBuilder.resolveTargetDevice` require exact UDN equality (never falling through to Tier-3 on UDN mismatch), and `WidgetConfigStore` / `WidgetActionExecutor` persist and self-heal canonical UDNs alongside real serials.
   - **Tier 3 / Passes 3a & 3b (Exact Endpoint → `<friendlyName>` Fallback + Cross-Device Claim Protection)**: Used **only** when at least one side lacks a real serial and canonical UDN; both `findMatchingExistingDevice` and `findMatchingDiscoveredDevice` prefer exact `(ipAddress, port)` (Pass 3a) before `<friendlyName>` (Pass 3b), while `isDiscoveredClaimedByOtherDevice` prevents offline blank-serial switches from hijacking a peer's discovered hardware.
3. **Automatic Room Inference, Canonical Grouping & Non-Destructive Legacy Room Migration ([`DeviceEntities.kt`](../../app/src/main/java/org/suppressingfire/wemi/data/DeviceEntities.kt))**:
   - **`normalizeDeviceNameForInference(deviceName)`**: Splits acronym-to-CamelCase (`"WCLight"` → `"wc light"`, `"TVDenLamp"` → `"tv den lamp"`) and lower-to-upper CamelCase boundaries (`"StairwayLight"` → `"stairway light"`) and replaces `_`, `-`, `/`, `.` with spaces before lowercase token matching.
   - **`inferRoomFromName(deviceName)`**: Evaluates declarative `ROOM_INFERENCE_RULES` in specificity order:
     1. **`"Kitchen"`**, **`"Dining Room"`**, **`"Ensuite"`** (evaluated **before `"Bedroom"`** so `"Master Bath"`, `"Guest Bathroom"`, and `"Kids Bath"` resolve to **`"Ensuite"`**).
     2. **`"Hallway & Landing"`** (`\bhall\b`, `\bstair` prefix for `stair`/`stairs`/`stairway`/`staircase`, `"landing"`, `"foyer"`, `"entry"`, `"mudroom"`, `"corridor"`, `"breezeway"`).
     3. **`"Bedroom"`**, **`"Outdoor"`** (with `\bpier\b`), **`"Garage"`** (with `\bshed\b`, `"toolshed"`, `"woodshed"` so `"Finished Basement"` never matches Garage), **`"Basement"`**, **`"Office"`**, **`"Living Room"`** (with `\bden\b`).
     4. **`"Hallway & Landing"`** floor fallback (`"upstairs"`, `"downstairs"` — only when no specific room like `"Upstairs Bedroom"` or `"Upstairs Office"` matched).
     5. **`"Unassigned"`** (`UNASSIGNED_ROOM`) fallback.
   - **`normalizeRoomName`, `groupDevicesByCanonicalRoom` & `resolveDeviceRoomAssignment`**:
     - `normalizeRoomName` maps blank, whitespace-only, and case-variant `"unassigned"` values to `UNASSIGNED_ROOM`; `groupDevicesByCanonicalRoom` merges case-variants (`"Kitchen"` + `"kitchen"`) and sorts `"Unassigned"` last across `MainActivity.kt`, `TvScreen.kt`, and `SwitchWidgetConfigureActivity.kt`; `resolveDeviceRoomAssignment` trims `existingRoomName`, preserves custom user rooms and Demo Showroom rooms, and migrates blank / `"Unassigned"` / legacy `"Living Room"` switches automatically.
4. **Zero-Permission Subnet Home Sync & Soft-AP SSID Shielding (`sanitizeAndResolveInitialLanHome`, `syncFirstRouterSsid`, `mergeDiscoveredMetadata`, `isWemoDeviceSetupSsid` in [`HomeProfileSanitizer.kt`](../../app/src/main/java/org/suppressingfire/wemi/data/HomeProfileSanitizer.kt) & [`XmlAndSkuParser.kt`](../../app/src/main/java/org/suppressingfire/wemi/network/XmlAndSkuParser.kt))**:
   - Unescapes XML entities and filters out Belkin soft-AP SSIDs (`WeMo.Switch.xxx`, `Wemo.LS3W.xxx`, `WeMo.Light.xxx`, `WeMo.Mini.xxx`) from `GetMetaInfo` field 4, preserves already-known router SSIDs on re-adoption, syncs valid router SSIDs onto generic home labels without stale `HomeNetworkEntity` clobbering, and repairs polluted multi-home `HomeNetworkEntity` / `DeviceEntity` rows on startup using each device's own home/subnet.

## 2. Six Non-Negotiable Discovery, Room Grouping & Release Invariants

Whenever modifying `DeviceEntities.kt`, `DiscoveryCoordinator.kt`, `HomeProfileSanitizer.kt`, `ProvisioningCoordinator.kt`, `DeviceCrudAndRulesCoordinator.kt`, `LanRuntimeUtils.kt`, `XmlAndSkuParser.kt`, `SsdpDiscoveryEngine.kt`, `NetworkClient.kt`, `DeviceDescriptorFetcher.kt`, `SwitchRepository.kt`, `DeviceActionsUiController.kt`, `MainActivity.kt`, `TvScreen.kt`, `TvRoomSectionHeader.kt`, or `widget/*.kt`, verify all six invariants:

1. **Unrecognized or Blank Names/Rooms Must Default to `UNASSIGNED_ROOM` (`"Unassigned"`), Never `"Living Room"`**:
   - Keep `UNASSIGNED_ROOM` as the fallback in `inferRoomFromName`, normalize rooms via `normalizeRoomName` (merging case-variant `"unassigned"`), group via `groupDevicesByCanonicalRoom` across `MainActivity.kt`, `TvScreen.kt`, and `SwitchWidgetConfigureActivity.kt`, and keep `"Unassigned"` sorted after all named rooms.
2. **Evaluate Specific Functional Rooms (`"Ensuite"`) Before Broad & Floor Modifiers (`"Bedroom"`, `"upstairs"`/`"downstairs"`)**:
   - Compound names like `"Master Bath Vanity"`, `"Upstairs Bedroom"`, `"Upstairs Office"`, and `"Downstairs Living Room"` must resolve to their specific functional room.
3. **Short Ambiguous Tokens Must Use Pre-Compiled Word-Boundary Regexes**:
   - Always use `WORD_BED_REGEX` (`\bbed\b`), `WORD_HALL_REGEX` (`\bhall\b`), `WORD_STAIR_PREFIX_REGEX` (`\bstair`), `WORD_PIER_REGEX` (`\bpier\b`), `WORD_SHED_REGEX` (`\bshed\b`), `WORD_DEN_REGEX` (`\bden\b`), `WORD_GIRL_REGEX` (`\bgirl\b`), `WORD_BOY_REGEX` (`\bboy\b`), `WORD_KID_REGEX` (`\bkid\b`), and `WORD_WC_REGEX` (`\bwc\b`) after `normalizeDeviceNameForInference`.
4. **All Discovery, Provisioning, Manual-IP Save, GENA Push, Widget & Reconnect Flows Must Enforce 3-Tier / Symmetric 4-Pass Identity & `resolveDeviceRoomAssignment`**:
   - Never bypass real-serial or canonical-UDN mismatch protection (including inside `probeWemoPort`, `executeWithPortHealing`, `ProvisioningCoordinator`, and `WidgetRemoteViewsBuilder.resolveTargetDevice`), never allow offline blank-serial switches to hijack peer hardware, always unescape XML entities in `/setup.xml` and `GetMetaInfo`, never overwrite hardware `<friendlyName>` via `ChangeFriendlyName` when Name is left blank, and never overwrite custom user room assignments.
5. **Unit, Governance, Widget & E2E Tests Must Pass (`102/102` Kotlin across `20` suites + `0` lint errors, `100644` script modes)**:
   - Verify all `20` suites (`ExampleUnitTest`, `SkuAndCryptoTest`, `RuleAndTransportTest`, `SoapAndSelfHealingTest`, `RepositorySelfHealingTest`, `DiscoveryAndGroupingIntegrationTest`, `BatchAndCrudIntegrationTest`, `LifecycleAndConcurrencyTest`, `GenaProvisioningAndRulesTest`, `TelemetryDiagnosticsTest`, `LicenseAndBrandGovernanceTest`, `ExampleRobolectricTest`, `EndToEndUiTest`, `ProvisioningAndGenaCujE2ETest`, `TvAndHeaderLayoutE2ETest`, `TvNavigationAndScenesE2ETest`, `HardwareCujEndToEndTest`, `HomeScreenWidgetTest`, `HomeScreenWidgetUiE2ETest`, `AppFlowsAndManagementE2ETest`) with `sh gradlew testDebugUnitTest --rerun-tasks lintDebug assembleDebug`.
6. **Stage 2 Release Review & Zero-Idle-Polling Stop Policy**:
